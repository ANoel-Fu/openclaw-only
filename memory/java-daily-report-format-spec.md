### 3. 格式细节

#### 标题
- 主标题：`# 📚 Java 学习日报 - 第 X 天 (YYYY-MM-DD)`
- 副标题：`💡 每天 5 道题，系统掌握 Java 面试核心知识点`

- 统计：`## 📊 今日学习统计`

#### 分隔线
- 使用 `---` 分隔各部分

#### 加粗
- 问题：`**Q: 问题？**`
- 答案标题：`**✅ 答案：**`
- 来源标题：`📖 **来源：**`

#### 链接
- 格式：`[点击查看解析](URL)`

#### 列表
- 使用 `• ` 作为列表符号
- 编号格式：`• 1.内容`

- 支持加粗：`**关键词**`
- 支持列表：`• 列表项`
- 分段清晰，每段之间空一行

**Q: Java 为什么是跨平台的？**

**✅ 答案：**

Java 的跨平台能力主要依赖于 JVM（Java 虚拟机）：

**工作原理：**
• 1.编译阶段：Java 源代码通过 javac 编译成字节码
• 2.运行阶段：不同操作系统安装对应版本的 JVM
• 3.关键设计：字节码是平台无关的，JVM 是平台相关的

**重要理解：**
• 跨平台的是 Java 程序（字节码），不是 JVM 本身
• JVM 是用 C/C++ 开发的编译后程序，不能跨平台
