# AI/科技日报 - 自动化脚本

## 📋 功能说明

每天上午 9 点（北京时间）自动执行：
1. 抓取配置的 RSS 源
2. 去重、分类、摘要
3. 生成 Markdown 格式日报
4. 通过飞书推送给用户

## 🚀 手动触发测试

```bash
# 测试抓取（不发送）
node /root/.openclaw/workspace/scripts/tech-daily-fetch.js --dry-run

# 完整执行（发送飞书）
node /root/.openclaw/workspace/scripts/tech-daily-fetch.js --send
```

## 📦 依赖安装

```bash
cd /root/.openclaw/workspace
npm install rss-parser node-fetch
```

## 🔧 配置说明

编辑 `config/tech-daily-cron.json` 自定义：
- 数据源（RSS 地址）
- 推送时间（cron 表达式）
- 分类标签关键词
- 最大条目数

## 🔥 热门资讯
