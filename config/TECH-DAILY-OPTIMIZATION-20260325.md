## 🔧 技术要点

### Lightpanda 使用

```python
LIGHTPANDA_BIN = "/root/.local/bin/lightpanda"

def fetch_with_lightpanda(url, timeout=25):
    cmd = [
        LIGHTPANDA_BIN,
        "fetch",
        "--dump", "markdown",
        "--log_level", "error",
        "--http_timeout", "20000",
        url
    ]
    result = subprocess.run(cmd, capture_output=True, text=True, timeout=timeout)
    return result.stdout if result.returncode == 0 else ""
```
